## 🎨 Design Philosophy & Features

- **Editorial Aesthetic:** Traditional university library, dark wooden shelves, scholarly journals, archival manuscripts, and parchment textures.
- **Palette:** Deep Forest Green (`#19372D`), Warm Ivory (`#F6F1E7`), Parchment (`#EDE4D4`), Antique Gold (`#AA925E`), and Deep Burgundy (`#682C37`).
- **Typography:** *Cormorant Garamond* (English headings), *Noto Serif Devanagari* (Hindi headings and prose), and *Source Sans 3* (body text and metadata).
- **First-Class Mobile Experience:** Fully responsive fluid grid layouts tested across viewports from `320px` to `1920px` with zero horizontal overflow.
- **Bilingual Interface:** Real-time seamless language toggle (`हिन्दी` / `EN`) with synchronized `<html lang="...">` attributes.
- **Interactive Source Verification Ledger:** Transparent audit trail modal linking every academic claim to verified institutional documents.
- **Dynamic Citation Generator:** One-click copy tool supporting APA, MLA, and Chicago citation styles.
- **Accessibility:** WCAG 2.2 AA compliant contrast ($>12:1$), keyboard navigation, ARIA dialogs, touch targets $\ge 44\text{px}$, and `prefers-reduced-motion` support.
